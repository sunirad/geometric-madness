Установка репозитория с нуля:
    git clone https://github.com/sunirad/geometric-madness.git
    cd geometric-madness
    code .

Загрузка изменений в репозиторий: 
    git status
    git add .
    git commit -m "что было сделано типа в этом пул реквесте я пососал яйца"
    git push origin 

Загрузка изменений с репозитория:
    git pull origin

Если активный мердж реквест:
    git add .
    git commit -m "Complete merge"
